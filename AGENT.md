# AGENT.md

Entry for make.fun's "The Funniest Sick-Day Excuse" bounty: a single funny sick-day excuse line, written by `main.py` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` as fallback), exactly the line with no trailing newline.

Run it with `python3 main.py`. Pure Python stdlib (`import os` only), deterministic, no network.
