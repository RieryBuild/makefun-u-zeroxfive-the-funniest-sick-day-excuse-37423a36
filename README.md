A sick-day excuse where a runaway Roomba drags the wifi router into the street and a neighbor's dog takes it hostage.

## Run it

```sh
python3 main.py
```

The script writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt` when the variable is empty or unset), exactly the line with no trailing newline.
